# Paper workflow

Kept here rather than in `latex/README.md` because that file is mirrored into
the Overleaf project, where setup instructions are noise for co-authors. This
file stays in `context_sok` only.

## The two repos

| repo | holds | who edits |
|---|---|---|
| `context_sok` | everything, including `latex/` | you, via Claude |
| `context_poison_paper` | a mirror of `latex/` only | Overleaf co-authors |

They are **not** linked automatically. The mirror is refreshed by hand.

## The rule: pull, regenerate, edit, push

```bash
git subtree pull --prefix=latex git@github.com:Nyamtulla/context_poison_paper.git main --squash
```

```bash
python3 scripts/gen_paper_numbers.py
```

```bash
python3 scripts/gen_paper_figures.py
```

Then edit, commit, and send it back:

```bash
git subtree push --prefix=latex git@github.com:Nyamtulla/context_poison_paper.git main
```

Regenerate **after** pulling, never before. `gen_paper_numbers.py` rewrites
`latex/numbers.tex`, and pulling on top of a freshly generated file conflicts
in a generated artifact.

## If subtree push is rejected

It means the mirror has commits the local split does not contain, which is
what happens when someone edits in Overleaf or directly on GitHub. Find out
what is actually different before doing anything forceful:

```bash
git fetch git@github.com:Nyamtulla/context_poison_paper.git main
```

```bash
for f in $(git ls-tree -r --name-only FETCH_HEAD); do r=$(git rev-parse FETCH_HEAD:$f); l=$(git hash-object latex/$f 2>/dev/null || echo MISSING); [ "$r" = "$l" ] || echo "DIFFERS: $f"; done
```

A file that differs is either their edit or yours. Check `git log FETCH_HEAD`
to see which. `git subtree pull --squash` can fail with "'latex' was never
added" because the subtree was created by a push rather than by
`git subtree add`; in that case take their version of the affected files by
hand, as above, and push again.

## Building

There is no LaTeX toolchain on this machine. The source is written for
Overleaf, which has `acmart` installed. Set `main.tex` as the main document and
the compiler to pdfLaTeX.

With a local toolchain:

```bash
latexmk -pdf latex/main.tex
```

## Rules for co-authors

- Do not edit `latex/numbers.tex`. It is generated, and a hand-typed number
  there is silently overwritten on the next regeneration.
- Do not type counts into prose. Every corpus-derived figure is a macro
  (`\NCorpus`, `\NDefenses`). If a needed figure has no macro, ask for one.
- Do not edit `latex/figures/*.pdf`. They are generated by
  `scripts/gen_paper_figures.py`.
