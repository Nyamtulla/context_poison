## What to do

Save each PDF anywhere inside **`data/papers/`**. Filenames don't matter — the
extractor matches on content, and hand-typed paths have caused a real error in
this project before. Tell me when you've done a batch and I'll extract and code
them.

## Worth knowing before you spend time

These 36 are **low-citation and survey-heavy**. The highest is 27 citations and
most are under 10; several titles are surveys or curriculum papers that will
likely code as contributing no mechanism and no defense. The high-value papers
are all already retrieved — StruQ, SecAlign, Spotlighting, BIPIA, Open-Prompt-
Injection, Attention Tracker, and both Greshake papers are in hand. **Skipping
this list entirely is a defensible choice**; it would be recorded as a known
boundary rather than a silent gap.

If you do want them, IEEE is 24 of the 36 — one institutional login covers
two-thirds.
