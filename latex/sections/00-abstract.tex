Two research communities study the same failure in large language model
agents, and neither tests the other's work. Security researchers study the
context an attacker changes on purpose; safety researchers study
context that becomes wrong on its own. Either way the model cannot tell which
part of its context deserves trust. We measure that separation. We read
\NCorpus{} papers in full and recover \NPureTrackPairs{} confirmed (defense,
attack) pairs. Only \NCrossCommunityPairs{} of them (\PctCrossCommunity{}\%)
cross between the communities, and one direction is all but closed:
\textbf{\NSecDefVsSafetyAttack{} security defense in our corpus has ever been
evaluated against a safety failure mechanism}, against
\NSecDefSecAttack{} evaluated against security attacks. The dates show the two sides reaching the same ground in turn
rather than together. Both communities have named a failure in \NSharedChannels{} channels.
Security names it first in \NChannelsSecFirst{} of them, and safety in none, by up to \MaxChannelLag{} years.

So we ran the missing experiment. We executed \NCampaignPairs{} (defense,
attack) pairs across \NCampaignImpl{} implementations and \NCampaignEpisodes{}
scored episodes. Every method runs from its authors' released code and
weights. We check each pair against an undefended model on the same items.
Even where nine tenths of the honest document survives, not one of them leaves
the model better off than no defense at all. The reason is a single mechanism.
Each of these defenses has one dial: how far to trust the retrieved document
against how far to trust the model's own memory. Turning it moves errors
between the two without creating correct answers. The attacker wrote part of
that document. Trust the document more, and the attacker receives what memory
would have supplied. Trust memory more, and memory takes it back. The two
movements almost exactly cancel. Neither direction helps. The attacker's text
sits inside the same document that the defense must judge. One defense does
resist. It gives the retrieved text less weight when that text makes the model
less certain. So we wrote a passage that makes the model more certain. That
turns the weighting off, and cuts the defense's advantage over an undefended
model by 58\%.
