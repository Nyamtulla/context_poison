LLM agents answer from their context, so whoever controls the context
controls the answer. Two literatures study this failure. Security papers
study context an attacker changes on purpose; safety papers study context that
becomes wrong on its own. To the model, both are text in the same context
window.

We read \NCorpus{} papers in full and recovered, and checked against a
written checklist, every case where a paper tested a fix against a named
cause. Only \NCrossCommunityPairs{} of
\NPureRegimePairs{} tested pairs cross between the two literatures, and none tests a security
fix against a cause from a safety paper. The two sides divide the problem rather than
duplicate it: security fixes act where text enters the context, safety fixes
where the model reasons about it, and the two sets of papers rarely cite each
other. We then coded how \NDesignFixes{} retrieval fixes were evaluated. The
number of passages a fix is tested on follows the question it asks, not its
literature, and three choices do separate the literatures: what the bad text
competes with, whether results are split by what the model already knew, and
whether the attacker adapts to the fix. A test that crosses the literatures
therefore has to give each fix the input it was built for.

Run that way, safety fixes that decide how far to trust the document hand
the answer to an attacker who wrote it, and the one that resisted loses
\PctAcdRemovedGradient{}\% of its protection to an attacker who knows its
rule. The reverse test, security defenses against honest mistakes, needs data
neither literature has. We build one dataset that states each false claim as
one passage and inside ranked sets, in an attacker version and in versions of
real honest mistakes. In a pilot, \PctSdTwoAllOk{}\% of its planted passages
pass a blind hand reading, against \PctSdOneAllOk{}\% when built by string
matching.
