\section{Results}
\label{sec:results}

This section answers RQ3 to RQ5. Every retrieval result runs a safety fix on
one passage, the format it was built for (Section~\ref{sec:testing}), and
compares it with the undefended model and the same model with no document,
on the same items.

\subsection{RQ3: Does a fix built for one literature's problem survive the other's?}

The methods built for honest error all decide how far
to trust the retrieved document over what the model already knows. Trusting
the document more is right when the document is out of date, and wrong when an
attacker wrote it. Six of the seven safety fixes we report work this
way: ACD, CK-PLUG, COIECD, ParamMute, SCR and SpARE.
None of them uses any signal that separates a real document from a planted
one. When the document is honest and newer than the model's memory, leaning
on it helps. When an attacker wrote it, leaning on it moves the model toward
the attacker's answer.

Table~\ref{tab:family} shows the benefit turning into a loss. The safety fix SpARE changes accuracy by
+\ESpareClean{} points on a clean context and by \ESpareSat{} on a corrupted
one, both beyond its threshold. The safety fix ParamMute gains \EParamClean{} points on a clean context
and ends \EParamSatGap{} points below the undefended model on a corrupted one.
The safety fix SCR, the one method in this family that asks the
model to judge between its own answer and the document's, gains
\EScrSatGain{} points on a corrupted context and costs \EScrCleanCost{} on a
clean one, roughly five times what it gains.

Start with the no-document score. The safety fix DyPRAG holds \EDypragClean\% on a clean
context and \EDypragSat\% on a corrupted one while the undefended model falls
from \EDypragRagClean\% to \EDypragRagSat\%. Read alone, that looks like
complete resistance. The same model with no document at all scores
\EDypragNoRet\%, which is not measurably different. DyPRAG is unaffected
because it is not reading the document, and only a no-document score shows
this.

The reverse direction, security defenses against honest mistakes, is not
answered here. The security defenses that vote across passages need a ranked
set, and the data that would test them fairly does not exist in either
literature (Section~\ref{sec:testing}); Section~\ref{sec:dataset} builds it,
and the security defenses RobustRAG, ReliabilityRAG, Spotlighting, PIGuard and
DataSentinel run on it next.

Answer to RQ3. In the direction we can test fairly, no. Safety fixes built
for honest error lose to an attacker when they shift the model's trust toward
the document: the benefit they show on a clean context turns into a loss on
a corrupted one. The one fix that is unaffected, DyPRAG, is unaffected
because it does not read the document. The reverse direction waits for the
shared dataset.

\paragraph{The form of the planted passage.}
\label{sec:payloads}
What a fix does depends on the form of the planted
passage, not on which cause it came from. The safety fix ACD is the only method that both
uses a clean document and resists corpus poisoning: it ends
\EAcdSatGain{} points above the undefended model on a corrupted context.
Corpus poisoning, though, was optimized to fool a retriever, not ACD, so this
shows only that ACD resists that one passage. We then planted a fluent false
sentence instead, holding everything else fixed. Table~\ref{tab:acd} shows
the protection disappear. ACD's rule depends on how uncertain a passage makes the model. An optimized token string is incoherent and raises uncertainty, so ACD
discounts it. A fluent false sentence lowers uncertainty, so ACD trusts it
more, and the defended model ends below a model given no document at all.

Three more methods show the same dependence on form
(Table~\ref{tab:payloads}). The safety fix ParamMute is harmful against both forms, by
\EParamExcessCorpus{} and \EParamExcessFalse{} points, but how well it
suppresses the model's wrong memory falls from \EParamCorpusPmDrop{} to
\EParamFalsePmDrop{} points. Under corpus poisoning the wrong answer lives
only in memory, so suppressing memory removes it. Under false evidence it
lives in memory and in the planted passage, and ParamMute reaches only the
first. For the safety fix CK-PLUG, the effect on accuracy moves from \ECkCleanCost{} to
\ECkSatDelta{} points under corpus poisoning and stays near
\ECkFalseOffset{} under false evidence.
The safety fix COIECD changes nothing measurable against either.

We do not rank the two forms. Before running them we wrote down the result
that would contradict our explanation: a fix doing better against false
evidence than against corpus poisoning. The safety fix CK-PLUG does, with \ECkExcessFalse{}
points of excess damage, compared with \ECkExcessCorpus{}. Both forms leave the
undefended model near the floor, at \ECkUndefFalseCorrupt\% and
\ECkUndefCorpusCorrupt\% for CK-PLUG and \ECoiecdFalseCorrupt\% and
\ECoiecdCorpusCorrupt\% for the safety fix COIECD, so excess damage compares two near-total
collapses and has little room to separate them. We report CK-PLUG's result as
an exception this data cannot resolve, and compare fixes only within one
form.

\paragraph{Where the answers go.}
\label{sec:distractor}
No fix moves a measurable share of answers toward
the real document.
When the planted passage repeats what the model already believes, a correct
answer from memory and a copied answer look the same. We therefore built a
passage asserting a third answer, neither the true one nor the model's own,
by changing one word in the item's own evidence sentence. An output can then
be read three ways: the true answer means the model read the real document,
its own answer means it recalled from memory, and the third answer means it
copied the planted passage. With nothing planted the third answer appears
\EDistCleanBase\% of the time, and \EDistCleanNoRet\% of the time from a
model given no document.

The safety fix ParamMute suppresses answers from memory, and the suppressed answers go to
the attacker. It cuts answers from memory from \EPmDistPmBase\% to \EPmDistPmDef\%, and copying rises from
\EPmDistCopyBase\% to \EPmDistCopyDef\% almost one for one, while correct
answers stay below the threshold. The safety fix ACD does the reverse. It cuts copying from
\EAcdDistCopyBase\% to \EAcdDistCopyDef\%, and the answers it refuses to copy
go back to memory, not to the real document. The safety fix CK-PLUG copies \ECkDistCopyDefCorrupt\%, compared with its undefended
model's \ECkDistCopyBaseCorrupt\% (Table~\ref{tab:distractor}).

The two movements are one effect. Every one of these methods chooses
between the document and the model's memory, and the attack is inside the
document. Turning the setting toward the document gives answers to the
attacker; turning it toward memory gives them back to memory. Neither setting
reaches the real document, because the choice they make cannot separate a real
document from a planted one. Methods that turn toward memory also lose a share
of answers to neither outcome: \EAcdResid{}, \EScrResid{} and
\ESpareResid{} points for the safety fixes ACD, SCR and SpARE.

\paragraph{An attacker who knows the fix.}
\label{sec:adaptive}
Every attack above was
built without knowledge of the fix it met. If a fix loses to such an attack, it would also lose to
a stronger one. If it holds, that shows little. The safety fix ACD was our only holding result, so we
attacked it directly.

ACD blends the model's answer with and without the document, weighted by how
uncertain each one is. The attacker controls only the document, so the attack
has one goal: make the document look certain. This also sets a limit. A
perfect attack of this kind turns ACD into the undefended model and cannot
push it below that. We committed to that limit, and five further predictions,
before building the attack.

We built two attacks. The first tries five phrasings of the same false claim
for each item and keeps the one ACD finds most certain. The second appends a
short suffix found by gradient search against the same goal. Both keep the
false answer fixed, so any change comes from the form alone.

All six predictions held (Table~\ref{tab:adaptive}). The fair measure is
ACD's margin over the undefended model, because both attacks also hurt the
undefended model. The rephrasing attack removes \PctAcdRemovedBestOf\% of
that margin. The gradient attack removes \PctAcdRemovedGradient\%, while doing
less damage to the undefended model than the rephrasing attack, so it is
attacking ACD's rule specifically. With nothing planted ACD and the
undefended model differ by at most \NAcdGapCleanMax{} points under all three
passages, so the attacks act only through the planted text. ACD
degrades but does not collapse: by the bands we set in advance it keeps some
protection, and it never falls below the undefended model.

\paragraph{The assumption behind the failure.}
\label{sec:neither}
The safety fixes assume the document is honest. They decide how far to trust
it over the model's memory, and an attacker writes the document. The one fix
that resisted, ACD, did so because of the form of the attack text, not
because it recognized an attack: its rule discounts a passage that raises the
model's uncertainty, an optimized token string does, and a fluent false
sentence does not. The security defenses rest on assumptions of their own,
stated in their papers: the voting defenses certify their answer while
corrupted passages are few~\cite{xiang-2024-certifiably,shen-2025-reliabilityrag},
and the filters look for an injected instruction. An honest mistake need not
respect either. A fact that changes can leave many retrieved passages wrong
at once, and a stale page carries no instruction. Whether these assumptions
fail in practice is what the reverse direction tests.

Answer to RQ4. A shared assumption, not a defect of individual methods. The
safety fixes all choose between the document and the model's memory, and
that choice cannot separate a real document from a planted one. Turning the
choice toward the document hands answers to the attacker; turning it toward
memory gives them back to memory, never to the real document. The one fix
that resisted did so because of the form of the planted text, and an
attacker who knows its rule removes \PctAcdRemovedGradient{}\% of that
protection.

\subsection{RQ5: Taken together, do the two literatures solve context poisoning?}
\label{sec:together}

First, the two sides defend different stages. Security fixes act where text
enters the context window and safety fixes act where the model reasons about
it: \NDefPtIngestionSec{} security fixes act at ingestion and
\NDefPtReasoningSafety{} safety fixes at reasoning
(Section~\ref{sec:parallel}).

Second, nothing joins the stages. No fix in the census acts at both, no paper
in the corpus combines a fix from each side, and only
\NCrossCommunityPairs{} of \NPureRegimePairs{} tested pairs cross between
the two literatures (Section~\ref{sec:emptycell}).

Third, the stage that safety fixes defend fails when an attacker writes the
input (RQ3), and the agent experiment shows which stages hold.
The agent experiment pairs only security methods with security attacks, so
it does not test transfer, but it shows where a defense has to act to hold.
\NAgentHolds{} of \NAgentConditions{} defense and attack combinations drive
the attack's success to zero, and every one of them acts before the agent
reads the injected text or before it acts on it. None of the
\NAgentTriedReasoning{} combinations that act while the model reasons holds.
In this experiment, the stage at which a defense acts separates the defenses
that hold from those that do not.

Answer to RQ5. No, as the two literatures stand. Their fixes act at
different stages, no published work joins those stages, and neither
literature tests its fixes against the other's failures. The reasoning stage
that safety fixes defend hands the answer to an attacker, and in the agent
experiment only defenses that act before the model reads the bad text, or
before it acts, hold. Whether the ingestion stage holds against honest
mistakes, and whether a system built from both stages holds where each fails
alone, are the next measurements, and the shared dataset of
Section~\ref{sec:dataset} is built to make them.
