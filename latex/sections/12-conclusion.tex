\section{Conclusion and future work}
\label{sec:conclusion}

Two literatures study one failure: an LLM agent reads content it should not
trust and cannot tell which content that is. Security papers call the
content an attack; safety papers speak of failures and conflicts. Over
\NCorpus{} papers read in full, the two divide the problem rather than
duplicate it. Security fixes act where text enters the context and safety
fixes where the model reasons about it, \PctSameRegime{}\% of tested (fix,
cause) pairs stay inside one literature, and none tests a security fix
against a cause from a safety paper.

How each literature tests explains part of the gap. A fix is tested on the
input its question needs, one passage when it weighs a document against
memory and a set when it chooses among passages, and the literatures differ
in what the bad text competes with, whether they split results by what the
model already knew, and whether the attacker adapts. A test across them has
to respect all of this, and our first attempt did not: joining ten passages
into one broke some safety fixes, and we withdrew those runs.

Run on its own format, a safety fix that decides how far to trust the
document cannot separate a real document from a planted one. Leaning toward
the document hands answers to the attacker who wrote it, and leaning toward
memory gives them back to memory, never to the real document. The one fix that resisted did so because of the form of the
attack text, and an attacker who knows its rule removes
\PctAcdRemovedGradient{}\% of that protection. Taken together, the two
literatures do not close the gap: their fixes act at different stages, no
published work joins them, and in an agent experiment only defenses acting
before the model reads the bad text, or before it acts, hold.

The reverse test needs data neither side has, so we built it: each false
claim as one passage and inside ranked sets, in an attacker version and in
versions of real honest mistakes, with every planted passage checked to state
its false answer. Building it also showed that most released PoisonedRAG
passages in our sample deny their own target.

\paragraph{Future work.}

\textbf{Run both directions on the shared dataset.} Freeze the construction
rules, build the full dataset with a hand-checked sample, confirm that every
fix reproduces its own published benefit on it, and then run security
defenses against honest mistakes and safety fixes against attacks, each in
its own format.

\textbf{Measure a composed system.} Put a fix from each stage in one
pipeline and measure whether it holds where each half fails.

\textbf{Extend the adaptive case.} Every context-reliance fix other than ACD
has had only non-adaptive attacks, which is no evidence of robustness. Each
exposes a quantity an attacker can address, and the same two optimizers
apply.

\textbf{Close the supply-chain and cross-modal gaps.} These channels have
fewer named fixes than named causes and are the routes by which agents accept
third-party capability.
