\section{Conclusion and future work}
\label{sec:conclusion}

Two research communities study one failure. An LLM agent reads content it
should not trust, and it cannot tell which content that is. The security
community calls the content an attack and builds defenses. The safety community speaks of failures and conflicts and builds methods to mitigate them. We call the content a mechanism and the countermeasure a fix. We measured the distance between them over \NCorpus{} papers read in full,
of which \NAnalysed{} name a mechanism or a fix.
\PctSecCitesSafety{}\% of security-regime papers cite a safety-regime one. Only \NBothValidated{} of \NFixes{} fixes were
tested in both regimes. And \PctSameRegime{}\% of
tested (fix, mechanism) pairs stay inside a single regime. One direction of the
cross-testing matrix holds \NSecDefVsSafetyAttack{} pair in \NPureRegimePairs{}: a
security fix has been evaluated against a safety
mechanism exactly once.

We then ran that experiment, in both directions. \NCampaignPairs{} pairs,
all on the authors' released artifacts. \PctCampCross{}\% of them cross the
boundary the literature does not. One planted passage in ten gives a fix its
best chance, because nine honest passages survive, and it is the attacks' own
default. Across both directions, \NGridLowHelps{} of \NGridLowPairs{} (fix,
mechanism) pairs show a resolvable benefit there, both against the refusal
attack. The finding is an explanation, not a verdict.

In the first direction, fixes built for honest error meet attackers.
Context-reliance fixes do not fail because someone built them badly. They fail because of the choice they make. Each one decides between trusting the context and trusting memory,
and that dial moves correctness around without creating any. Suppress memory
and the attacker receives what memory held. Suppress the attacker and memory
receives it back. A planted passage that asserts a third answer separates copying from
remembering, so
we can add the two movements together. In the three fixes that suppress
memory they cancel to within \NDistCancelMax{} points. Neither movement shifts anything toward the real document, because the dial has no setting for it. The attack
is inside the context.

In the second direction, a fix built against an attacker meets honest
mistakes. The votes of the security defenses RobustRAG and ReliabilityRAG work while wrong passages
are few, which is the setting their authors assume. When half the retrieved
passages are copies of one out-of-date page, both give the outdated answer
more often than no fix does. When the copies are reworded, ReliabilityRAG
still gives it more than half the time, but the model with no defense
catches up. Against a failure that plants no false answer, they have nothing
to act on. The defenses that look for injected instructions find none in an
honest mistake and change nothing. One method did work on honest
mistakes: AttnTrace, which traces an answer back to the passages it came
from. With the passages in random order, when the model gave the outdated
answer, the passage AttnTrace ranked first was a stale one \ETraceTopStale\%
of the time. When the model answered correctly, it was a stale one
\ETraceTopCorrect\% of the time. This rests on one model and \NTraceStale{}
wrong answers. The two directions fail for opposite
reasons: the safety fixes assume the document is honest, and the security
defenses assume wrong passages are few or carry an instruction. Each
assumption holds in its own regime and fails in the other.

Taken together, the two communities do not solve context poisoning. Security
defends where text enters and safety where the model reasons, no published
work joins the two stages, and each stage's fixes fail on the failures the
other stage is built for. A system assembled from both literatures places
each failure in front of a fix that was not built for it. We measured one
such system, a security filter in front of a safety fix. It did no better
than its stronger half on any case, and the attack PoisonedRAG passed both
halves.

Two further results sharpen the first direction's claim. First, protection depends on the \emph{form} of the planted passage, not only
on whether an attacker is present. An evaluation built around optimized
passages therefore overstates how well a system holds. Second, one fix did resist. It loses \PctAcdRemovedGradient{}\% of that
protection to an
attacker who reads its rule and optimizes against the quantity it measures.

\paragraph{Future work.}

\textbf{Extend the adaptive case to the rest of the family.} We tested the
one fix that resisted,
with two optimizers. A best-of-five search over sentence forms took
\PctAcdRemovedBestOf{}\% of
its protection. A gradient search over token ids took
\PctAcdRemovedGradient{}\%. Together they
settle that the fix degrades rather than collapses.
Every other context-reliance method in the campaign has had only the
non-adaptive treatment, which Section~\ref{sec:experiments} states is no
evidence of robustness at all. The same two optimizers transfer directly: each
of these methods exposes a scalar the attacker can address.

\textbf{Close the supply-chain and cross-modal gaps.} These channels have fewer
than one named fix per named mechanism and are the routes by which agents
accept third-party capability. They are where new fixes are most needed.

\textbf{Test the stage finding across regimes.} In the agent experiment,
every defense that held acts before the agent reads the injected text or
before it acts, and none that acts while the model reasons holds. That
experiment pairs only security defenses with security attacks, on one agent
model. Whether the stage at which a fix acts also predicts which fixes work on
the other community's problem needs fixes from both communities, run inside
one agent harness.

\textbf{Make cross-community testing routine.} The deepest
problem this paper documents is not any single fix. It is that who runs an experiment predicts its
outcome, and that nothing in current practice corrects for this. A shared harness would fix this. It should pair fixes with mechanisms that a
taxonomy selects, not mechanisms that either author selects. Transfer then
becomes a measured property rather than an assumed one. We release ours.
